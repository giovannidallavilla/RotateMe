This is the pre-release of my first audio plugin "RotateMe".
RotateMe is a Leslie 147 emulation that aims to preserve the original and warm sound of the physic rotary speaker.
RotateMe has some simple, but useful, features such as:

Pre-saturation stage with two different saturation types and drive parameter.
The original Leslie 147's two operation modes: Chorus (slow) and Tremolo (fast).
The brake feature to temporarily stop the effect.
Dry/Wet parameter.
A simple preset browser to save or inspire you with different factory presets.
The pre-release is compiled for Windows, MacOS and Linux on VST3 and AU formats.
Copy the relatives files into your plugin working directory.
Usually:

Windows (VST3): C:\Program Files\Common Files\VST3
MacOs (AU): /Library/Audio/Plug-Ins/Components
MacOs (VST3): /Library/Audio/Plug-Ins/VST3
Linux (VST3): /usr/lib/vst3
